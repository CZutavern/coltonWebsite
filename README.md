# Colton Zutavern - Personal Portfolio & Systems Showcase

The official portfolio and interactive systems showcase for Colton Zutavern, accessible at [coltonzutavern.com](https://coltonzutavern.com).

Built with **Next.js 15 (App Router)**, **React 19**, **TypeScript**, and **Tailwind CSS**.

---

## Featured Engineering Projects

- **Jeep Computer & Telemetry:** In-dash automotive computer, active DSP sound processing, optoisolated HEI tachometer circuit, and environmental data logging on Raspberry Pi 5.
- **Multi-Agent AI Orchestration:** Autonomous distributed agent network across homelab infrastructure with local LLMs, strict tool sandboxing, and mobile telemetry.
- **High-Fidelity Audio DSP:** Multi-channel automotive DSP crossover network running on CamillaDSP with real-time ALSA stem routing and hardware amplifier control.
- **Core Memories & Hardware:** Ferrite core memory design and coincident-current matrix driver circuitry.

---

## Tech Stack

- **Framework:** Next.js (App Router, Turbopack)
- **Language:** TypeScript
- **Styling:** Tailwind CSS, PostCSS
- **Deployment:** Self-hosted Linux production server with Cloudflare edge caching and Nginx reverse proxy

---

## Development

```bash
# Install dependencies
npm install

# Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
npm start
```
